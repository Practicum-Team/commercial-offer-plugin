# Подготовка данных для шаблона КП

Модуль `document_preparation.py` извлекает названия полей из DOCX и собирает данные для заполнения.

`prepared_content()` берёт дату, итог, скидку и НДС из проверенного расчёта. Из профиля подставляется контактное лицо компании. ФИО подписанта, заказчик, телефон, электронная почта, сроки, предоплата и реквизиты остаются незаполненными, пока их не подтвердит пользователь.

`missing_fields()` возвращает список незаполненных полей. До получения обязательных данных документ не следует считать готовым к отправке.

Модуль не меняет `company_docx.py` и существующие шаблоны. Он подготавливает данные для его аргумента `content` и проверки полноты перед генерацией. Значения расчётных полей нельзя менять вручную.
