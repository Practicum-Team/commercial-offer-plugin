# Дополнительные модули бэкенда

`advanced_quote.py` — расчёт заказа с использованием правил из профиля. Вход: результат `load_profile()`, список позиций и параметры заказа. Для компьютерного сервиса поддерживается скидка по действующей карте; нестандартные условия ремонта, выезда и предоплаты требуют отдельных входных параметров и не рассчитываются автоматически. Для копицентра предусмотрены скидки по количеству, категориям, комплектам и карте, но исходный `rules.json` содержит ошибку синтаксиса, поэтому сначала требуется исправить исходные данные.

`company_docx.py` — генерация документа по исходному русскоязычному шаблону. Неизвестные плейсхолдеры не заменяются произвольным текстом: при отсутствии значений возвращается ошибка с перечислением полей. Для получения DOCX необходимо передать все текстовые реквизиты и раздельные итоги по работам и оборудованию.

Это промежуточный этап. До включения в полный сценарий следует согласовать правила совместимости скидок, проверить расчёты на эталонных запросах и исправить исходный JSON копицентра. Исходные файлы профилей в этом пакете не изменяются.

Запуск проверки из корня проекта:

```bash
python -m pytest -q
```
