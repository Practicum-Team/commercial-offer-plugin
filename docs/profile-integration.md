# Подключение учебных профилей

Модуль `profile_adapter.py` читает каталог, прайс и правила из `profiles/<имя компании>`.
Он не изменяет исходные файлы и не обращается к базе данных.

Поддерживаются два формата CSV: русские столбцы компьютерного сервиса и английские столбцы копицентра. При конфликтующих актуальных ценах расчёт прерывается.

Для компьютерного сервиса реализована проверка явно указанной дисконтной карты и порогов общей стоимости покупки. Для копицентра реализован расчёт скидок по количеству для отдельных категорий, но текущие исходные JSON-файлы копицентра содержат синтаксические ошибки и поэтому не загружаются.

**Ограничения:** модуль пока не рассчитывает комплексные скидки, предоплату, услуги с особыми условиями, накопительные и совмещаемые скидки, правила выезда. Такие заказы завершаются ошибкой вместо произвольного расчёта. Для компьютерного сервиса базовая скидка по карте применяется к простым позициям заказа; специальные ограничения в отдельных категориях требуют расширения.

Пример использования:

```python
from datetime import date
from commercial_offer.profile_adapter import load_profile, calculate_profile_quote

profile = load_profile("profiles/company_comp_service")
quote = calculate_profile_quote(
    profile,
    [{"product_id": "1", "quantity": 15}],
    on_date=date(2026, 11, 1),
    discount_card=True,
)
print(quote["grand_total"])
```

Выход содержит позиции, сумму, скидки, ссылки на строки прайса и идентификаторы применённых правил.
