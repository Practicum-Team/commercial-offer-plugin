## Документы профиля и их проверка

Обязательные документы (назначение определяется при импорте, не по имени):
catalog, prices, rules, cases, profile, template.

Конфликт имён: если файл с тем же именем уже есть и содержимое отличается —
агент запрашивает `--overwrite yes|no`. Идентичные по SHA-256 файлы пропускаются.


## Схема-файл (data-schema.json), которую возвращает LLM при загрузке профиля в БД

{
  "profile_name": "company_a",
  "version": 1,
  "files": [
    {"filename": "catalog.csv", "kind": "catalog",
     "field_map": {"product_id": "id", "name": "title", "category": "cat"},
     "payload_columns": ["описание"]},
    {"filename": "prices.csv", "kind": "prices",
     "field_map": {"product_id": "id", "amount": "price",
                   "currency": "cur", "valid_from": "from", "valid_until": "to"}},
    {"filename": "rules.json", "kind": "rules"}
  ]
}

## Коды неточностей → `обязательные_уточнения`

| Код | Когда |
|---|---|
| quantity_unspecified | количество во мн.ч. не указано |
| ambiguous_rules | правило неоднозначно |
| conflicting_requirements | взаимоисключающие требования |
| unit_mismatch | единица измерения не совпадает с каталогом |
| missing_product | товара нет в каталоге |
| insufficient_budget | бюджет отсутствует или недостаточен |
| incomplete_request | запрос неполный |
